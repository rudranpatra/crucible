Attack engines

Static analysis where it's reliable. Real execution where it counts.

SupplyChainAgent
Unpinned actions, script injection, token scope — real YAML analysis
TimingAgent
Injects real delays before each step, observes the real exit code
EnvCorruptionAgent
Null, overflow, type-mismatch on env vars via a live probe script
StepReorderAgent
Runs step commands out of order, surfaces real dependency failures
NetworkChaosAgent
Real curl probes: latency spikes, DNS flaps, connection resets
DependencyDriftAgent
Mutated requirements resolved by the real pip resolver
